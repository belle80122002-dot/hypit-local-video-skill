# 原素材剪辑技法地图

版本：2026-09-22。共 72 项，分为剪接、叙事、时间、声音、转场、画面整理六组。这是面向实拍的工作库，不声称囊括所有流派、商业插件和不断出现的模板。剪接技法、叙事结构与后期处理分别标记，不能把调色等同于剪接。

## 用法

先读素材，再按问题打开对应文档；一次通常选 2–4 项核心技法，必要的声音与字幕整理另计。数量只是帮助聚焦，不是配额。长片可以多用，完整口播也可以只做可靠的自然硬切。没有合适素材就不用，不能为了展示技法破坏句义或动作。

| 重读、卡壳、句子接得生硬 | [连续性与剪接](cuts-and-continuity.md)、[声音](sound-editing.md) | C02、C09、C11、A01–A04 |
| 画面都有了，但看不懂在讲什么 | [叙事](story-and-structure.md) | N01、N03、N04、N11 |

每项均给出用途/素材条件、具体动作、失败检查、执行级别。文中秒数和处理强度如有出现，只是试剪起点，不是平台规则。

## 执行级别

- **B：基础 EDL**。助手看素材后确定选段、顺序、片段字幕；现有 edit_video.py 按计划硬切。B 不代表自动识别或自动审美。
- **E：另写本地处理/时间线**。需要助手编写、运行并检查 FFmpeg 处理，或按官方 Hypit 文档制作组件；当前基础脚本没有这个开关。
- **N：有相应能力的剪辑器**。必须确认实际安装的软件和版本。没有工具时保留计划并采用可用替代，不能声称完成。

详见 [执行边界与实例](execution-recipes.md)。B+E 表示选段可以用基础 EDL，附加处理另做；不是两个字母都默认已执行。

## 原素材工作流

1. 建来源表：文件、时码、帧率、音轨、可用动作、镜头前后余量、语句、可信度。
2. 用 [内容类型方案](footage-playbooks.md) 确定保留信息与观看目的。
3. 写 [剪辑决策记录](../examples/edit-decisions.md)：每个切点为什么切、采用哪个编号、是否具备条件。
4. 按执行级别制作，先试最难的一个接缝，再扩展到全片。
5. 分开记录“计划采用”“已渲染”“已看画面”“已试听”。黑场、尾字、动作重复、字幕闪烁都回到时码修正。

术语核对和进一步学习见 [研究来源](research-sources.md)。其中内容类型方案与取舍规则是本项目的编辑建议，并非厂商保证，也不要求安装付费软件。
