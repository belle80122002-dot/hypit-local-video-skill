# 按原素材选剪法

这些是组合起点，不是所有片子强制套用的模版。具体编号先查 [技法地图](editing-techniques.md)，执行级别查 [执行说明](execution-recipes.md)。

## 1. 完整版口播 / 课程

先整理完整有效句子和论点；标重读、口误、待定停顿，不按固定目标时长删观点。
优先 C02 + T01 + F07。剪口脸部跳跃时，有相关细节就试 C11 + A02；没有覆盖镜头，保持可接受硬切，高清时可少量 C09。
先剪声音且不丢条件词、否定、数字；再核对画面和嘴型。不要为去卡壳重新生成用户声音。交付删除清单，说明保留哪次重读。
不用：每句话加叠化、全片快速变速、未审查的 Morph cut。

## 2. 萌宠 / 家庭日常

先找真实动作链：注意到物件→接近/尝试→变化→反应。可用 N02 引出亮点，再 N01 讲清过程。
优先 C06 + C10 + C13 + T02；关键叫声保留，配乐 A06 让位。趣味字幕是编辑旁白，不能写成动物真的说出某句话。
没有第二机位就不硬造正反打。反应镜头要对得上事件；回放需让观众知道是回放。结果已很有趣时不要再堆闪白/故障效果。

## 3. Vlog / 旅行 / 生活

先按地点或当天活动建立小段落，保留人物和环境关系。N03 + N07 + A08 可串起过程；素材真有同向甩镜或遮挡时才用 V03/V04。
风景镜头、人物表达、现场声轮换，不把所有片段同长度卡点。慢片允许停留。不要拿后拍的天气画面当作当天发生事实。

## 4. 教程 / 录屏

先列不可省略的操作步骤及结果。N01 + N11 + C10 + F09 优先；长等待用 N08 或 T06 并说明压缩。
文字和鼠标必须可读，演示快于解释时宁可分段。配音轨稳定，窗口切换不切断话语。关键失败提示不能因“不好看”删除。
竖屏裁不下整个界面时，用局部展示加全局交代，不强行裁掉必要按钮。

## 5. 产品 / 手工 / 美食

先保留材料、步骤、变化、成品之间的真实关系。C10 + N07 + T03，可在形状确实相似时用 V09。
保留接触声和质感细节；对比画面必须同条件或清楚标明差异。展示效果不能靠调色、速度或角度伪造产品性能。

## 6. 访谈 / 婚礼 / 活动多机位

先 C15 同步全部机位，A05 选主音轨，再 C12/C16 按讲话和反应切换；用 A01/A02 维持声画流动。
核对片首、中、尾是否漂移。现场原音的重要性通常高于音乐卡点。异时拍摄的掌声或表情，不剪成某句发言的真实回应。

## 7. 音乐 / 舞蹈 / 运动

动作完整和同步优先 C06 + T02 + T03。需要看清动作可 T05/T09，局部强调可 T07；有同期音乐的多机位先同步到同一段表演。
不要把不同拍的半个动作接成不可能完成的动作；比赛或教学中的慢放/回放须标识。切镜不能只是遮掉表演失误却声称完整实录。

## 8. 照片 + 视频混剪 / 纪念片

照片用 F03 控制视线，视频保留关键原音；用 N11 分时期、V01 表达时间流逝。
不强行给所有照片生成运动人物；本地推拉已可增加节奏。封面 F10 使用清楚且获得使用授权的照片。

## 9. 纪录 / 新闻 / 证言

优先 N01、C08、A05、F07。保留来源时间与语境；重排不能改写事实、制造回答另一个问题的印象。
若使用异时异地说明素材，明确说明。戏剧化声效、倒放和假反应不适合未经标注的证言。

## 10. 预告 / 精华 / 实验表达

用户明确要精彩短版或表达性作品时，可组合 N02/N04/N12 + T04，风格转场只选择少数 V 类。
先确定核心承诺和回报，再压缩。若用户要完整内容则不能擅自使用这条路径。宣发文案不承诺“必爆”。

## 素材不足时

没有细节覆盖：尝试更好的硬切点或保留短停顿。
没有可用原音：明确采用字幕叙事和音乐，不能凭空转写。
没有转场余量：缩短/取消转场，不冻结源尾帧冒充正常运动。
没有高帧率：先试原速或轻度慢放，检查质量后决定。
没有 API 或预算：继续现有素材、本地字幕、混音与合成；生成镜头不属于必要步骤。
