# 把剪辑决定变成实际时间线

先读 [本地脚本字段](local-tools.md)。技法库是助手的工作指导；不是 72 个已经写入脚本的一键功能。下面的时码是教学示例，需要替换成实际看片结果。

## 能力边界

| 任务 | 当前配套脚本 | 助手还需要做什么 |
| --- | --- | --- |
| 选段、重排、硬切、按片段字幕、等比留边 | 已有 | 人工/视觉分析定 EDL，再预览 |
| 口播自动识别重读 / 自动找最佳切点 | 没有 | 转写、看片、逐句判断 |
| J/L、B-roll 覆盖、声音桥、动态 ducking | 没有 | 制作独立声画轨并渲染 |
| 叠化、遮罩、画中画、变速、跟踪、动态文字 | 没有 | 本地滤镜/组件或可用剪辑软件 |
| Morph cut、复杂自动跟踪 | 没有 | 确认所用软件确实支持，先试短段 |
| 新镜头、云端配音 | 没有 | 只有获得对应服务授权才另行调用 |

不要往基础 EDL 填一个 `transition`、`speed` 或 `broll` 字段就声称实现了效果：当前解析器可能忽略不认识的字段。进阶决定写入独立的 [决策表](../examples/edit-decisions.md)，由另一个明确实现这些操作的工程/命令执行。不能将只包含硬切的结果标作已完成高级技法。

## A01：一个具体 J-cut

目标：时间线第 5.0 秒换成 B 画面；提前 0.4 秒听到 B。

- A 画面：时间线 0.0–5.0。
- B 的源音频 9.6–10.0：放在时间线 4.6–5.0。
- B 的源画面和音频从源 10.0 开始：均放在时间线 5.0 以后。
- A 的语句必须在 4.6 秒前有合理结束；保留的 A 底声另做淡化。避免两个人无意同时说话。
- B 在源 9.6 前后必须真的有对应声音，不能倒移整段音轨造成嘴型错位。
- 预览 4.0–6.0：先听到 B、后看见 B，B 出画后的嘴型同步才算成立。

A02 则相反：假设第 5.0 秒切画面，A 的语音可继续至 5.4；B 画面这段应是反应/细节等不会产生嘴型误配的画面。声音延长到哪里，需要真实源素材支持。

## C11 + A02：删口误后用细节覆盖

1. 先生成保留完整句义的主声音轨，记录每段源时码到输出时码的映射。
2. 在画面接缝两侧找到相关细节，放到上层画面；其自带声音按内容决定静音或保留。
3. 主音轨持续播放，细节结束后回到对应时刻的主画面。
4. 不要简单把带原声的细节片段塞进串联 EDL，否则会打断原有语句。
5. 检查回到人物时嘴型和姿态，听有没有重复词、被吞掉的辅音。

## V01：重叠转场的时长

若 A 长 3 秒、B 长 4 秒，两者重叠 0.3 秒，则总长是 6.7 秒，B 从时间线 2.7 秒开始。声音是否同样交叉淡化要独立决定。不要把“镜头画面重叠”误算成简单相加，也不要只缩短视频却保留 7 秒音频。

居中转场需要两边有足够源帧余量；不够就调整入出点、缩短转场或改硬切。先输出包含接缝的短段，检查重影与冻结帧。

## T05 / T07：变速与字幕

源 10.0–12.0 共 2 秒，以 0.5 倍输出就是 4 秒。字幕和后续镜头按输出时间重排，源时间保持原记录。速度坡度另记每个源区间与输出区间；声音可以保持独立常速叙事，或有意同步变速，不能未处理就混在一起。

低帧率慢放先比较重复帧与可用插值结果，尤其检查手、羽毛、杯口、运动遮挡。质量不合格就减弱或取消。

## 本地实现入口

FFmpeg 可用的基础入口包括 `trim/atrim`、`setpts/asetpts`、`overlay`、`xfade/acrossfade`、`atempo`、`volume`、`sidechaincompress`、`crop/scale`、`subtitles/ass`。先检查本机滤镜列表与对应帮助；多输入滤镜要统一必要的分辨率、帧率、像素格式、时间基与起始时间。参见 [FFmpeg 官方滤镜文档](https://ffmpeg.org/ffmpeg-filters.html)。

这是实现入口，不是可直接运行的通用命令。助手应为当前项目生成可复查命令/脚本，先试短段，再全片运行、解码和检查视听。字幕时间、声画偏移、缺音轨都必须纳入测试；高级滤镜未运行成功时保留基础版并说明缺项。

使用 Hypit 时先读官方 `hypit` Skill 对应的 Author / Film / 组件资料；不要假定所有剪辑器效果都存在同名 Hypit 参数。已有本地处理结果可以按官方素材导入流程复用；需说明哪些效果已经烘焙进媒体、哪些仍能在时间线调整。

## 验收：不能只看文件生成

保存采用的技法编号和输出时码。至少检查最难接缝前后、变速起终点、每处字幕换行与音乐收尾。进阶合成额外检查总时长、嘴型、重影、遮罩边缘和裁切。实际播放/试听不可用时明确标为待验证，不能用技术解码结果代替。
